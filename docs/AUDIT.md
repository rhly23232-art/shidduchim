# ביקורת מערכת (Audit) — שידוכים

תאריך: כ״ט בחשון תשפ״ז (2026-11-09) · נקודת שמירה לפני הביקורת: ענף `backup/before-changes-review`.
המסמך נכתב **לפני** שינויי הקוד, על בסיס קריאת הקוד בפועל, הרצת `npm audit` ובדיקות קיימות.
סטטוס הטיפול בכל ממצא מתועד בעמודה "טיפול" ומתעדכן ב-`docs/RELEASE_READINESS.md`.

## 1. מפת המערכת

| שכבה | מימוש בפועל |
| --- | --- |
| ממשק | React 18 + TypeScript strict + Vite 6, ‏Tailwind + רכיבי shadcn/Radix (`src/components/ui`), מסכים ב-`src/pages`, תכונות ב-`src/features/*` |
| מצב (state) | TanStack Query (מטמון שרת), מצב סינון ב-URL (`useFilters`), מצב מקומי ברכיבים; אין store גלובלי |
| שכבת נתונים | ממשק אחד `DataApi`/`AuthApi` (`src/lib/api/types.ts`) עם שלושה מימושים שנבחרים בעלייה: **Supabase** (ייצור), **מסד claude.ai** (Artifact), **הדגמה מקומית** (IndexedDB) |
| היסטוריה | `journaled()` עוטף כל backend ורושם שמירה/מחיקה ליומן (`journal`) — היסטוריה וסל מחזור |
| שרת | Supabase: Postgres + RLS, ‏RPC `save_candidate` (טרנזקציה אחת), View ‏`candidates_view`, Storage (`resumes`, `journal`), Edge Function ‏`send-resume-email` (Resend) |
| אינטגרציות | Resend (מייל עם קובץ מצורף, דרך Edge Function), ‏Gmail (בתוך claude.ai דרך MCP של המשתמש), ‏mailto (גיבוי ידני) |
| קבצים | ZIP/DOCX/XLSX נכתבים ונקראים בדפדפן ללא תלות (`src/lib/files`), PDF ו-Word מוצגים ב-pdf.js ו-mammoth |
| AI | **אין יכולות AI במערכת.** |
| עבודות רקע | אין (אין שרת אפליקציה). פעולות "רקע" רצות בדפדפן (ייבוא, גיבוי). |
| בדיקות | `scripts/verify-rls.ts` (31 בדיקות בידוד). בדיקות E2E קיימות רק מחוץ למאגר (נכתבו במהלך הפיתוח) — **לא חלק מהפרויקט**. אין בדיקות יחידה. אין CI. |
| פריסה | build סטטי (Vite), ‏migrations ב-`supabase/migrations`, הוראות ב-README. אין מסמך פריסה/rollback. |

מודל מסחרי בפועל: **חשבון לכל שדכן/ית**, הפרדה מלאה בין חשבונות (RLS לפי `owner_id`). אין צוותים, תפקידים או חיוב.

## 2. מה עובד היטב

- בידוד נתונים בין חשבונות ב-Supabase: RLS על כל טבלה ו-bucket, ‏View עם `security_invoker`, ‏31 בדיקות עוברות.
- שמירת מועמד אטומית (RPC אחד: מועמד + משפחה + מחותנים).
- אילוצים במסד (אורכי שמות, טווח גובה/תאריך, סטטוס, רזומה אחד למועמד, גודל וסוג קובץ).
- ממשק אחיד ונגיש (axe ‏0 הפרות), RTL, רספונסיבי, מצבי טעינה/ריק/שגיאה.
- ייבוא/ייצוא אמיתיים (xlsx/docx/zip), היסטוריה, סל מחזור וגיבוי.
