## 3. מה מומש (חדש)

- 3 מיגרציות חדשות: `email_log`, ‏`concurrency`, ‏`account_deletion`. בנוסף `journal`, שנוצרה בשלב ההיסטוריה.
- Edge Function משוכתבת: הגבלת קצב, idempotency, ‏timeout, ניסיון חוזר, לוגים מובנים, ‏health check.
- עמוד "החשבון שלי" ומחיקה בשלושת ה-backends.
- דוח תקלות לתמיכה.
- עימוד בטבלת הרזומות (100 שורות בעמוד).
- קריאה מקבילית מהמסד.

לא נוספו יכולות AI. אין הצדקה לכך (ממצא 17).

## 7. תלויות חיצוניות (נדרש לפני ייצור)

1. פרויקט Supabase לייצור, והחלת 7 המיגרציות (`supabase db push`) **באישורכם**, אחרי גיבוי.
2. חשבון Resend, דומיין מאומת, וסודות `RESEND_API_KEY`, ‏`RESEND_FROM`, ‏`ALLOWED_ORIGINS`.
3. פריסת `send-resume-email`.
4. הגדרות Auth: אימות מייל פעיל, ‏SMTP, ‏Site URL.
5. אירוח סטטי עם rewrites.
6. (רשות) `VITE_ERROR_ENDPOINT` לאיסוף שגיאות.
